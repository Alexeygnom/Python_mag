# Описание
В файле main.py находится скрипт, который отправляет запрос по хэшу файла, получает JSON-ответ и выводит результаты сканирования.

## API ключ
Перед запуском необходимо задать API-ключ VirusTotal.

## PowerShell (Windows):
$env="ВАШ_API_KEY"

## Linux / macOS:
export VT_API_KEY="ВАШ_API_KEY"

## Скрипт:
отправляет запрос к VirusTotal API
получает JSON-ответ
выводит статистику сканирования
сохраняет полный JSON-ответ в файл result.json
