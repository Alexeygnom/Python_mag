# Описание
Данный проект представляет собой простой инструмент для автоматизированного мониторинга и анализа сетевой активности. Скрипт анализирует логи сетевых событий, выявляет IP-адреса с аномально высокой активностью и проверяет их репутацию с помощью API сервиса VirusTotal.

# Логика работы
- Скрипт загружает сетевые логи из файла network_logs.json.
- С помощью библиотеки pandas выполняется анализ логов и подсчёт количества обращений к каждому IP-адресу.
- IP-адреса, превышающие заданный порог активности, считаются подозрительными.
- Для таких IP выполняется запрос к VirusTotal API для проверки их репутации.
- На основе количества детектов и частоты обращений IP классифицируются как:
  - вредоносные (block),
  - подозрительные (alert),
  - безопасные (ignore).
- При обнаружении угроз выполняется имитация реагирования — вывод сообщения о блокировке или предупреждении.
- Результаты анализа сохраняются в файл report.csv.
- Для визуализации создаются графики распределения IP-адресов и статистики классификации угроз.
