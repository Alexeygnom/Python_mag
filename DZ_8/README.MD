# ДЗ 8 – Анализ сетевого трафика с использованием Scapy

## Описание работы
В данной работе выполнялся анализ сетевого трафика с использованием библиотеки Scapy.  
Целью являлось изучение структуры HTTP-запросов и ответов, а также выявление признаков XSS-атак в сетевом трафике.

## Содержимое репозитория
- **scapy_xss_analyzer.py**  
  Скрипт на Python для анализа сетевых пакетов и поиска признаков XSS
- **traffic.pcap**  
  Файл с перехваченным сетевым трафиком для анализа
- **report.MD**  
  Отчёт по выполненной работе
- **XSS_screen.pdf**  
  Скриншоты, демонстрирующие результаты XSS
