# Отчёт по ДЗ 8  

## Этап 1 – Подготовка среды
Была настроена среда для работы со Scapy.  
Установлены необходимые библиотеки и подготовлен скрипт для анализа сетевого трафика.

## Этап 2 – Сбор сетевого трафика
С помощью Scapy был выполнен перехват сетевого трафика при взаимодействии с веб-ресурсами.
В процессе перехвата были зафиксированы:
- исходящие TCP-соединения
- HTTP/HTTPS-запросы
- ответы серверов
Полученные данные были сохранены в формате `.pcap` для последующего анализа.

## Этап 3 – Поиск потенциальных XSS-уязвимостей
Был проведён анализ структуры HTTP-запросов и параметров передачи данных.
Рассматривались:
- параметры URL (GET)
- передача данных в теле запроса (POST)
- пользовательский ввод в запросах
На основе анализа были определены потенциальные точки, где может передаваться пользовательский ввод.

## Этап 4 – Анализ перехваченного трафика
Анализ `.pcap`-файла показал:
- наличие клиент-серверных взаимодействий
- передачу пользовательских данных в запросах
- различие размеров пакетов в зависимости от типа запроса
- обмен данными между несколькими удалёнными узлами
Скрипт на Scapy использовался для разбора и анализа пакетов.

## Изменения в трафике во время XSS-атаки

- Увеличение размера HTTP-запросов при передаче пользовательских данных  
- Появление параметров в строке запроса (GET)  
- Изменение содержимого HTTP-ответов сервера  
- Передача пользовательского ввода в параметрах URL  
- Отражение пользовательских данных в ответах сервера  
Такие изменения характерны для попыток внедрения XSS-полезной нагрузки, поскольку вредоносный код передаётся через параметры запроса и может быть отражён сервером в ответе.
